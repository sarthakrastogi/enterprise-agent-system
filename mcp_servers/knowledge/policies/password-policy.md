# Password and MFA Policy

- Passwords must be at least 14 characters. Passphrases are encouraged.
- Passwords are not rotated on a schedule; change yours immediately if you suspect it is compromised.
- Multi-factor authentication (MFA) is required for email, VPN and all cloud consoles. Use the authenticator app; SMS codes are only allowed as a backup.
- Never share passwords, including with IT staff. IT will never ask for your password.
- Use the company password manager for all work accounts. Personal password managers must not store work credentials.
- Lost MFA device: contact the IT helpdesk to have MFA reset after identity verification.
