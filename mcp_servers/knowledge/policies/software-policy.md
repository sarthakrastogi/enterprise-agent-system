# Software Installation Policy

- Software from the self-service catalogue can be installed without approval.
- Anything not in the catalogue needs a helpdesk ticket. IT checks licensing and security before approving; this usually takes 2 business days.
- Browser extensions are limited to the approved list. Extensions that read page content (for example, AI writing assistants) need security approval.
- Free or trial SaaS tools must not be used with customer or employee data unless security has approved them.
- Developers may install open-source packages from public registries for development, but production dependencies must pass the dependency scan.
